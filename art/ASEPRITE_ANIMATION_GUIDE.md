# Snow Ace — Aseprite 动画制作清单（像素路线）

## 通用原则（先看这个）
1. **分层 + 链接 cel**：每个角色拆图层，**不动的部件**（身体/头/躯干）放一层，把它的 cel **链接到所有帧**（右键 cel → Link Cels），永远只画一次；**动的部件**（袖/翅膀/光环/旗）单独成层，逐帧只改这几像素。
2. **帧数尽量少**：循环用 2–4 帧；靠 **ping-pong（来回）** 翻倍观感。8–12 fps 够用。
3. **首尾相接**：循环最后一帧要能接回第一帧，或直接用 ping-pong。
4. **每帧时长**：在时间轴设毫秒（如 100ms=10fps）。快速旋转/闪烁 60ms；待机/飘动 100–120ms；爆炸 80–100ms。
5. **Tag 命名**：框选该动画的帧 → 右键 New Tag，命名见下表（Godot 按名字取动画）。
6. **导出/接入**：存 `.ase` 给我，我配 Godot 导入（tag→SpriteFrames 动画）；若导入不顺，Aseprite 导出**横向 PNG 表**，我在 Godot 按网格切。
7. **AI 协作**：把 MJ/Seedream 出的静态定稿拖进 Aseprite 当**参考层（半透明锁定）**，描成干净像素定稿，再做动画。

## 优先级（先做这批就能跑）
- 🔴 **必做**：玩家 `fly`、爆炸 `boom`、Boss `idle`+`hit`
- 🟡 **建议**：各杂兵 `idle`（没有也行，先静态）
- 🟢 **可选**：子弹闪烁、拾取旋转、激光流动

---

## 🚀 玩家·飞天巫女（32×20，必做）
- **图层**：身体头（静·链接）/ 袖·飘带（动）/ 灵力光环（动）
- **动画 `fly`**：3 帧 · 100ms · ping-pong
  - F1 静止基线
  - F2 袖/飘带向上飘 1–2px、光环变亮变大
  - F3 袖/飘带向下落 1–2px、光环变暗变小
- 💡 身体层全程链接，只动袖和光环；这就是"飞在空中"的灵动感。

## 💥 爆炸（48×48，必做）
- **图层**：单层即可（或 火球 + 烟 两层）
- **动画 `boom`**：6–8 帧 · 90ms · **不循环**（one-shot）
  - F1 小亮点 → F2–F4 火球膨胀到最大、最亮 → F5–F6 颜色转暗 → F7–F8 化烟消散
- 💡 不用太精细，爆炸很" forgiving"。

## 👾 敌弹·鬼火（12×4，建议）
- **动画 `flicker`**：2 帧 · 60ms · 循环（F1 火大、F2 火小+偏移）→ 满屏鬼火就有"活"的感觉。

## ✈️ 玩家弹·符咒（16×4，可选）
- **动画 `spin`**：2 帧 · 80ms · 循环（符咒微微翻面/闪光）。

## 🔆 激光·灵力光柱（可选）
- **动画 `flow`**：2–3 帧 · 60ms · 循环（光晕沿 beam 平移一格，做出"流动"）。

## 杂兵 idle 循环（建议 2–3 帧，120ms，ping-pong）

| 敌人 | 图层(动) | 动画 `idle` 每帧动什么 |
|---|---|---|
| Basic 红鬼 | 螺旋桨/翅膀 | 2–3 帧转/扇 |
| Dive 俯冲 | 翅膀 | 2 帧 上/下扇 |
| Sniper 独眼炮 | 独眼 | 2–3 帧 眼光呼吸（可与开火同步加蓄光帧） |
| Rush 冲撞 | 尖刺/身体 | 2–3 帧 轻微抖动/蓄光 |
| Formation 甲虫 | 翅膀 | 2 帧 上/下扇 |
| RingShooter 环炮 | 旋转环 | 3–4 帧 旋转一格（最出彩的循环） |
| Spread 散射炮 | 核心/炮口 | 2 帧 呼吸 |

> 杂兵的身体层一律链接，只动上表那部分。

## 🏯 MidBoss 紫鬼战船（48×32，建议）
- **图层**：船身（静·链接）/ 帆·旗（动）/ 鬼脸眼（动）
- **动画 `idle`**：3 帧 · 120ms · ping-pong —— 帆旗飘 + 鬼眼光闪 + 船身可整体上下 1px。

## 👹 Boss 终魔王城（60×40，必做 idle+hit）
- **图层**：城堡主体（静·链接）/ 旗·幡（动）/ 鬼脸眼·嘴（动）
- **动画 `idle`**：3–4 帧 · 120ms · ping-pong —— 旗幡飘 + 鬼眼周期发光 + 嘴微张。
- **动画 `hit`**：1–2 帧 · 60ms —— 整体压扁 + 高光闪白（受击反馈，配合代码切到这帧）。
- （可选）`phase2`：鬼脸更怒（第二阶段用）。

## 🎁 拾取物（10×10，可选）
- **动画 `sparkle`**：2–3 帧 · 100ms · 循环 —— 缩放/旋转/闪光。

## Aseprite 操作速查
- 加帧：时间轴 `+` 或拖动。
- 复制 cel：选中 → `Ctrl+C` → 移到目标帧 `Ctrl+V`；或右键 Duplicate Cel。
- 链接 cel（静态层）：选中源 cel → 框选目标帧 → 右键 Link Cels。
- 洋葱皮：`View > Onion Skin`（或洋葱图标），调前后帧数。
- Tag：框选帧 → 右键 New Tag → 起名（如 `fly`）。
- 设帧时长：双击帧数字改 ms。
- 导出 PNG 表：`File > Export Sprite Sheet`（横向、间距 0）。

## Godot 接入（我来做）
- 存 `.ase`（保留 tag）丢进 `art/`，我配导入 → AnimatedSprite2D。
- 或你导出横向 PNG 表，我在 Godot SpriteFrames 按网格切。
- 每个动画名（`fly`/`idle`/`hit`/`boom`…）对上 Godot 节点，循环/单次、ping-pong 由我设。
