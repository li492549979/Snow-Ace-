# Snow Ace — 豆包 Seedream 5.0 pro 提示词（中文自然语言 / 像素风）

> 主题默认 = **日式神怪封建空战**（贴合《战国之刃》）。换主题只改场景词即可。

## ⚠️ Seedream 与 MJ 的不同（必读）
1. **用自然语言长句，中文最佳**：Seedream 不需要 MJ 那种逗号标签，按下面那样写成完整描述句效果最好。
2. **没有 `--ar / --v` 参数**：宽高比在「即梦」界面里选；走 API 则设 `size`（宽×高）。每条后面给了**目标画布**和**建议比例**。
3. **像素画要"先生成大图再缩小"**：直接生成 32×20 太小会糊。建议生成 **512~1024 长边**的像素风图，再在 Aseprite/PS 里用**最近邻缩小**到目标画布并修像素。
4. **不能输出真透明 PNG**：精灵都要求"纯深色单色背景"，生成后抠掉。
5. **像素画与精灵表仍需清理**：当作高质量草稿，进 Asebrush 收敛色板/去抗锯齿；动画帧 AI 不稳，建议手动补。
6. **保持整套统一**：用「图生图」功能，拿第 1 张定稿当风格参考图，后面每张都喂它，整套美术会协调很多。

## 📥 生成后处理流程
1. **抠背景**：Aseprite 魔术棒选纯色 → 删除；或 remove.bg / PS。
2. **收敛像素**：统一色板、去抗锯齿；先生成的大图用**最近邻缩小**到目标画布（玩家 32×20、杂兵 32×20、Boss 60×40…见下表）。
3. **动画**：精灵表切成等宽帧，或手动补帧，导出横排 PNG。
4. 存 PNG 放进 `art/` 对应子目录（player / enemies / bullets / effects / pickups / background）。
5. 丢给我，我接进场景（换占位色块 → Sprite2D/AnimatedSprite2D，2× 显示，建 ParallaxBackground）。
