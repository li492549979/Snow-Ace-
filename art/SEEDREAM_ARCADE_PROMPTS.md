## ⚠️ Seedream 5.0 Pro 使用要点（先读）

1. **用自然语言长句，中文最佳**：不要 MJ 那种逗号标签，按下面写成一整段描述句。
2. **没有 `--ar / --v`**：比例在「即梦」界面选；走 API 用 `size` 参数——支持 `1K / 2K / 3K / 4K` 或 `<宽>x<高>` 像素（如 `2048x2048`、`1280x720`），需与模型兼容（5.0 Pro 一般可到 2K~4K）。
3. **精灵不能直接生成小尺寸**：一律「大图生成 → 抠图 → 缩放到目标画布」。下面每条都给了「目标画布（宽×高）」和「建议生成比例」。
4. **背景必须用纯品红 `#FF00FF`**（不是黑色！）：街机风有粗黑描边，黑背景会和描边连在一起被抠掉。品红和角色颜色不撞色，能 100% 保留描边。生成后抠掉品红即可（Seedream 里加一句“背景为纯品红 #FF00FF，便于抠图”）。
5. **缩放方式**：街机风细节多，抠图后缩放到目标画布用 **Lanczos/双三次**（更平滑）；想要硬边颗粒感才用最近邻。
6. **动画帧 AI 不稳**：爆炸/待机动画建议先生成一张定稿，再用「图生图」补帧，或手动在 Aseprite/PS 里拆帧。单张精灵图（主体朝一个方向、无透视倾斜）AI 完成度最高。

## 🏞️ 背景：4 段 × 远/中/近 3 层（每层水平无缝平铺）

> 按视差拆成三层，**月亮一定放在远景（静止层）**，山和地面放中/近景（滚动层）：
>
> - **远景（Far，静止不动，0 速度）**：纯天空 + 月亮 + 星点，**画面里绝不能出现山脉、地面、建筑、树**。整幅不透明图，**不用品红背景**。
> - **中景（Mid，慢速滚动）**：远山 / 该段主体（古寺、竹林、魔城等）的**剪影**，纯品红 `#FF00FF` 背景，其余（天空部分）全部留成品红，抠成透明层叠在远景上。
> - **近景（Near，快速滚动）**：地面 / 前景细节（松枝、草木、熔岩等）的**剪影**，同样纯品红背景。
>
> ⚠️ 中/近景若生成成整幅不透明场景，会整层盖住远景。每层都做**水平方向可无缝平铺**；速度由我配（远 0、中慢、近快）。建议生成宽景（16:9 或 21:9、2048 宽），再裁切/缩放。

## 📥 生成后处理流程

1. **抠品红背景**：魔术棒选 `#FF00FF` 删除（即梦 / remove.bg / PS 均可）；品红与角色颜色不撞，描边能完整保留。

3. **动画**：爆炸等逐帧素材拆帧、对齐，导出横排 PNG。
4. **存 PNG**：放进 `art/` 对应子目录（player / enemies / bullets / effects / pickups / background），文件名与 `art/svg/` 里同名（`.svg → .png`）。
